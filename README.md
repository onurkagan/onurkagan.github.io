# onurkagan.github.io

The public pages of Onur Kağan Aldemir's games, served by GitHub Pages.

- `skyrazor/privacy/` — Skyrazor's privacy policy: https://onurkagan.github.io/skyrazor/privacy/
- `byahair/privacy/` — forwards to it (the game was called By a Hair until November 2026)

The policy's source is `docs/privacy-policy.html` in the game's repository; its
`tools/site/publish.sh` copies it here and pushes. Edit it there, not here.
